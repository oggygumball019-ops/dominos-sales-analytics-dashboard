# 🍕 Domino's Pizza Operational & Sales Analytics Dashboard

An interactive, end-to-end data analytics dashboard that analyzes transaction logs, revenue patterns, and customer retention metrics for Domino's Pizza outlets in Chennai.

## 📌 Features & Business Insights

* **KPI Summary Cards:** Tracks **Total Revenue (₹3.32M)**, **Total Orders (10K)**, **Active Customers (1K)**, and **Average Order Value (₹331.97)**.
* **Customer Retention Cohorts:** Monthly heatmap tracking user retention and repeat order behavior over an 8-month period.
* **Category & Outlet Breakdown:** Revenue distribution by pizza category (*Non-Veg Pizza*, *Veg Pizza*, *Pizza Mania*, *Sides & Desserts*) and top-performing outlets (*T. Nagar*, *Nungambakkam*, *Tambaram*).
* **Channel Performance:** Analyzes order sources (*Mobile App*, *Organic Web*, *Paid Social Ads*, *Referral*, *Google Search*).
* **Interactive Slicers:** Dynamic filtering by `outlet_area` and `category`.
